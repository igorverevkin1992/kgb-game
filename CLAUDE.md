# «Линия КР: Вашингтон, 1985» — заметки для Claude

Диегетический UI-симулятор резидента ПГУ КГБ в Вашингтоне 1984–1986. Однопользовательская
кампания на 7–10 часов, 4 акта. Платформа: **только Windows x64** (Steam + VK Play),
macOS и Linux не делаем.

## Документы
- `docs/plan.md`: утверждённый пошаговый план (шаги 0–19). Пользователь говорит
  «делаем шаг N», и ты сверяешься с этим файлом.
- `docs/concept/concept-bible.txt`: полный текст концепта (Concept Bible + GDD). По нему
  проверяй механику, числа, имена и тон. PDF-оригинал лежит рядом.
- `docs/README.md`: оглавление концепта с номерами строк.

## Стек и команды
Vite + React 19 + TypeScript (strict) + Zustand + Zod 4 (схемы контента, сообщения на русском).
Далее добавятся inkjs (диалоги) и Electron + electron-builder + steamworks.js (шаг 10).

```
npm run dev        # dev-сервер на :5173 (параметры отладки: ?act=1..4&lang=ru|en)
npm run validate   # проверка контента src/content (можно указать другую папку: npm run validate -- путь)
npm run check      # lint + typecheck + validate + unit + build — запускать перед каждым коммитом
npm run e2e        # Playwright (собирает и поднимает preview на :4173), скриншоты в test-results/screens
```

## Архитектура
- `src/engine/`: чистый TS без React и DOM. Вся игровая логика: неделя, риски, улики, флаги.
  Покрывается unit-тестами в `tests/unit/`.
- `src/content/`: игровые данные (JSON, Ink). Пользователь правит их сам, поэтому
  структура должна быть понятной, а ошибки валидатора — на русском. Памятка для пользователя:
  `docs/content-guide.md`. В игре контент грузит `loadContent()` из `src/content/index.ts`.
- `src/schemas/`: Zod-схемы контента. Тексты — `{ ru, en? }`, id с префиксами `tar_/clue_/cable_/op_/exam_`.
- `src/engine/content/`: разбор и проверка контента. `parse.ts` (схемы), `rules.ts` (ссылки,
  «Правило трёх улик», SDR, недели, длина текстов, полиграф), `simulate.ts` («идеальный игрок»
  для поиска софтлоков). CLI: `tools/validate.ts`. Новое правило — сразу с тестом в
  `tests/unit/validate.test.ts`, который портит настоящий контент.
- `src/engine/campaign/`: движок кампании. `dispatch(state, content, action)` — чистая функция:
  возвращает новое состояние + события или `error` по-русски, исходное состояние не мутирует.
  Неделя: утро (почта, донесения агентов) → день (`plan_op`) → вечер (`resolve_op`, `recruitment`)
  → ночь (`submit_report` завершает неделю: сверка лжи, пересчёт 4 рисков, концовки, следующий акт).
  Все числа — из `src/content/balance.json`, случайность — детерминированный `rng` в состоянии.
  Сохранения: `serialize` / `deserialize` (проверка Zod + ссылок на контент), `SaveStorage`.
- `src/ui/`: React. Стор `src/ui/store.ts` держит `CampaignState`, вызывает движок и
  автосохраняет в localStorage (`?new` — начать заново). Календарь недели — `ui/desk/Calendar.tsx`,
  сводка рисков и журнал — `ui/desk/AnalystSummary.tsx`.
- Сцена фиксированная **1600×900** (`ui/Stage.tsx`), масштабируется под окно. Все координаты
  предметов в `ui/desk/desk.css` — в пикселях сцены. Стена 0–300, стол 300–900.
- Кабинет `ui/desk/Desk.tsx`: предметы-кнопки (`desk-object-<view>`), клик открывает модуль.
  Открытый модуль — `ui/desk/ModuleView.tsx`: рамка + «край стола» с остальными предметами
  (`edge-<view>`), клавиши 1–7 (`ui/views.ts`), Esc — к столу. Без меню.
- Оболочки модулей — `ui/modules/Shells.tsx` (каждый шаг 4–8 заменяет свою оболочку настоящим
  модулем). Лоток почты — `ui/desk/Inbox.tsx`, вид документов по типу — `ui/documents/`.
- Арт-плейсхолдеры — SVG в `ui/art/DeskArt.tsx` (финальный арт — шаг 9). Диегетические сигналы
  рисков (отметки SOG на карте и т. п.) — `ui/signals.ts`.
- Шрифты в сборке (`ui/fonts.ts`): PT Mono — машинопись, PT Serif — американская пресса,
  PT Sans Narrow — бланки и ярлыки. Токены палитры — `ui/theme.css`.
- e2e: `tests/e2e/helpers.ts` — `playActions()` + `seedGame()` подкладывают в автосохранение
  состояние, собранное движком, чтобы тест начинался с нужного момента кампании.
- `src/i18n/ru.json` + `en.json`: все видимые строки. Ключи должны совпадать (это проверяет тест).

## Договорённости
- Пользователь немного программировал. Объясняй ключевые решения коротко и по-русски.
  Код пишешь ты, а тексты, баланс и решения по дизайну — за пользователем.
- Каждый шаг ведёт в свою ветку `step-N-<name>`. Шаг считается готовым, когда зелёные
  `npm run check` и `npm run e2e` и снят скриншот нового экрана.
- Персонажи пирамиды вымышлены (Варгас, Кэллоуэй, Хэйлс, Дженкинс, Мендоса, Колдуэлл
  «Кронос»). Реальные люди упоминаются только в историческом контексте и хронике.
  Тон: документальный нуар в духе ле Карре, без пропаганды.
- Отказ от «стены текста»: документ не длиннее 120–150 слов, модули открываются по актам.

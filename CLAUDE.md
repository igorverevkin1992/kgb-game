# «Линия КР: Вашингтон, 1985» — заметки для Claude

Диегетический UI-симулятор резидента ПГУ КГБ в Вашингтоне 1984–1986. Однопользовательская
кампания на 7–10 часов, 4 акта. Платформа: **только Windows x64** (Steam + VK Play),
macOS и Linux не делаем.

## Документы
- `docs/plan.md`: утверждённый пошаговый план (шаги 0–19). Пользователь говорит
  «делаем шаг N», и ты сверяешься с этим файлом.
- `docs/concept/concept-bible.txt`: полный текст концепта (Concept Bible + GDD). По нему
  проверяй механику, числа, имена и тон. PDF-оригинал лежит рядом.
- `docs/README.md`: оглавление концепта с номерами строк.

## Стек и команды
Vite + React 19 + TypeScript (strict) + Zustand. Далее добавятся Zod (схемы), inkjs (диалоги)
и Electron + electron-builder + steamworks.js (шаг 10).

```
npm run dev        # dev-сервер на :5173 (параметры отладки: ?act=1..4&lang=ru|en)
npm run check      # lint + typecheck + unit + build — запускать перед каждым коммитом
npm run e2e        # Playwright (собирает и поднимает preview на :4173), скриншоты в test-results/screens
```

## Архитектура
- `src/engine/`: чистый TS без React и DOM. Вся игровая логика: неделя, риски, улики, флаги.
  Покрывается unit-тестами в `tests/unit/`.
- `src/content/`: игровые данные (JSON, Ink). Пользователь правит их сам, поэтому
  структура должна быть понятной, а ошибки валидатора — на русском.
- `src/schemas/`: Zod-схемы контента (с шага 1).
- `src/ui/`: React. Стор `src/ui/store.ts` хранит состояние UI, а логику берёт из engine.
- `src/i18n/ru.json` + `en.json`: все видимые строки. Ключи должны совпадать (это проверяет тест).

## Договорённости
- Пользователь немного программировал. Объясняй ключевые решения коротко и по-русски.
  Код пишешь ты, а тексты, баланс и решения по дизайну — за пользователем.
- Каждый шаг ведёт в свою ветку `step-N-<name>`. Шаг считается готовым, когда зелёные
  `npm run check` и `npm run e2e` и снят скриншот нового экрана.
- Персонажи пирамиды вымышлены (Варгас, Кэллоуэй, Хэйлс, Дженкинс, Мендоса, Колдуэлл
  «Кронос»). Реальные люди упоминаются только в историческом контексте и хронике.
  Тон: документальный нуар в духе ле Карре, без пропаганды.
- Отказ от «стены текста»: документ не длиннее 120–150 слов, модули открываются по актам.

# Плейтест: как провести (шаг 10)

Цель: **не меньше 80% тестеров доходят до конца первой фазы операции, тупиков нет** (план, шаг 10).
Тестеров — 15–25 человек, лучше разных: любители детективов (Return of the Obra Dinn, Papers,
Please), стратегий и те, кто в такие игры не играет.

## 1. Сборка для тестеров

Сборку собирает GitHub Actions — компьютер не нужен:

```bash
git tag playtest-1
```

```bash
git push origin playtest-1
```

Или на GitHub: Actions → **Playtest** → Run workflow. Через 5–10 минут на странице Releases
репозитория появится архив `GodShpionov-playtest-1.zip`: игра, библиотека Steam и инструкция
для тестера `ПРОЧТИ.txt` (её текст — `docs/playtest-tester.txt`, можно править).

## 2. Что проверить самому до рассылки (на Windows)

- Игра запускается, звук есть, текст читается при 100% и 130%.
- **Steam Overlay.** Запустите Steam, затем игру: Shift+Tab должен открыть оверлей «Spacewar».
  В служебной папке (Esc → Настройки) внизу — «Steam: подключён». Без Steam — «не запущен»,
  игра работает как обычно.
- **Встроенная графика.** Если есть ноутбук без отдельной видеокарты — запустите там: стол должен
  работать плавно. Эффект старого экрана выключается в настройках.
- **Долгая сессия.** Поиграйте или оставьте игру открытой на час и посмотрите в Диспетчере задач,
  что память не растёт. (Автоматический тест на накопление узлов уже есть: `scenes_stability`.)

## 3. Во время игры

- Ничего не объясняйте заранее. Если играете рядом с тестером — молчите и записывайте, где он
  задумался, куда кликнул «не туда», что прочитал вслух.
- **Карта «Пути мысли»:** на листе — ряд шагов первой фазы (почта → доска мотивов → проверочный
  маршрут → встреча → выплата). Отмечайте, где тестер застрял, где перескочил шаг, где вернулся
  назад. После игры спросите, почему.
- F8 в игре — «застрял здесь»: тестер сам отмечает трудные места.

## 4. После игры: сводка журналов

Сложите присланные файлы `session-*.jsonl` в одну папку (можно по подпапке на тестера) и запустите:

```bash
tools/telemetry-report.sh путь/к/папке
```

Отчёт покажет: сколько дошли до конца первой фазы (цель — от 80%), где бросили игру, где
нажимали F8, где долго думали (простой больше 2 минут), какие действия чаще всего не получались
и сколько подсказок взяли. Пришлите мне отчёт и ответы тестеров — разберём и поправим.

## Журнал на компьютере тестера

Папка (Windows): `%APPDATA%\GodShpionov\telemetry\`. Сохранения — `%APPDATA%\GodShpionov\saves\`.
Журнал выключается в настройках («Журнал плейтеста»).

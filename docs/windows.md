# Как запустить «Год шпионов» на Windows

Игра — один файл `GodShpionov.exe`, установка не нужна. Подходит Windows 10 или 11 (64 бит).
Видеокарта — любая с поддержкой OpenGL 3.3 или DirectX 11, в том числе встроенная.

Сборку можно взять двумя способами: **A** — из последней проверки на GitHub (быстро, для себя),
**B** — со страницы Releases (удобно раздавать тестерам). Для обоих нужно войти в GitHub.

## Способ A. Сборка из последней проверки (CI)

1. Откройте https://github.com/igorverevkin1992/kgb-game и войдите в свой аккаунт GitHub.
2. Вверху страницы нажмите вкладку **Actions**.
3. Слева в списке выберите **CI**.
4. В списке запусков найдите верхний с зелёной галочкой и веткой **main**, нажмите на его название.
5. Прокрутите страницу запуска вниз до раздела **Artifacts**.
6. Нажмите **GodShpionov-windows** — скачается архив `GodShpionov-windows.zip` (несколько десятков мегабайт).
   Артефакты хранятся 30 дней; если раздела нет — откройте запуск поновее.
7. Переходите к разделу «Распаковка и первый запуск».

## Способ B. Сборка для плейтеста (Releases)

1. Откройте репозиторий → вкладка **Actions** → слева **Playtest**.
2. Справа нажмите **Run workflow**, ветка **main**, ещё раз **Run workflow**.
3. Подождите 5–10 минут, пока у запуска не появится зелёная галочка.
4. Откройте главную страницу репозитория → справа раздел **Releases** → верхний релиз
   «Плейтест: playtest-…».
5. В блоке **Assets** скачайте `GodShpionov-playtest-….zip`. Эту ссылку можно отправлять тестерам —
   внутри есть инструкция для них (`ПРОЧТИ.txt`).

## Распаковка и первый запуск

1. Найдите скачанный архив в папке «Загрузки».
2. Щёлкните по нему правой кнопкой → **Извлечь всё…** → укажите папку, например
   `C:\Игры\Год шпионов`, → **Извлечь**. Не запускайте игру прямо из архива: без распаковки она
   не найдёт библиотеку Steam рядом с собой.
3. В папке должны быть три файла: `GodShpionov.exe`, `steam_api64.dll`, `steam_appid.txt`
   (в сборке плейтеста ещё `ПРОЧТИ.txt`). Ничего из них не удаляйте и не переносите по одному.
4. Дважды щёлкните `GodShpionov.exe`.
5. Если появилось синее окно **«Система Windows защитила ваш компьютер»** — это потому, что у игры
   пока нет цифровой подписи издателя. Нажмите **Подробнее** → **Выполнить в любом случае**.
   Окно больше не появится.
6. Если антивирус задержал файл — добавьте папку игры в исключения. Ложные срабатывания на
   неподписанные игры на Godot случаются; сборка собрана из этого репозитория на GitHub Actions.
7. Откроется окно игры 1600×900. Окно можно растянуть или развернуть на весь экран (Win + ↑) —
   картинка масштабируется без искажений.

## Первые минуты в игре

- Перед вами стол резидента. Предметы кликабельны: карта, доска мотивов, шифрпункт «Фиалка»,
  финансовый журнал, магнитофон, лоток почты. Клавиши **1–7** открывают их напрямую,
  **Esc** — вернуться к столу, а на чистом столе — служебная папка (сохранения и настройки).
- Время недели переключает календарь справа: «Далее — день »».
- Игра сохраняется сама после каждого действия; при следующем запуске продолжится с того же места.
- **F8** — отметка «застрял здесь» в журнале плейтеста.
- Если трудно читать: Esc → **Настройки** → «Размер текста» 115% или 130%, «Эффект старого экрана»
  можно выключить, громкость — там же.

## Проверка Steam (оверлей и достижения)

1. Запустите клиент Steam и войдите в аккаунт.
2. Запустите `GodShpionov.exe` из папки игры (не через Steam — он о ней пока не знает).
3. Нажмите **Shift + Tab** — должен открыться оверлей Steam. В нём будет написано **Spacewar** — это
   тестовое приложение Valve, которое используется, пока у игры нет своей страницы в Steam.
4. Esc → **Настройки** → внизу строка «Сборка 0.10.0 · Steam: подключён».
   «Не запущен» — Steam выключен или файл `steam_appid.txt` лежит не рядом с игрой.
5. Достижения игры откроются только после настройки своей страницы в Steamworks
   (см. `docs/steam.md`); на тестовом «Spacewar» их не будет — это нормально.

## Где лежат файлы игры

Откройте проводник, вставьте в адресную строку `%APPDATA%\GodShpionov` и нажмите Enter:

| Папка | Что внутри |
|---|---|
| `saves\` | сохранения: автосохранение, три ручных слота, контрольные точки |
| `telemetry\` | журнал плейтеста `session-*.jsonl` — его присылают тестеры |
| `logs\godot.log` | технический журнал — пригодится, если игра упала или не запускается |

Начать с чистого листа: Esc → **Сохранения** → «Начать заново…». Или удалить папку
`%APPDATA%\GodShpionov` целиком (сотрёт все сохранения и настройки).

## Если что-то не так

| Что случилось | Что сделать |
|---|---|
| Окно игры чёрное или сразу закрывается | Обновите драйвер видеокарты (сайт Intel, AMD или NVIDIA). Если не помогло — запуск через DirectX, см. ниже |
| Подтормаживает на ноутбуке | Esc → Настройки → выключить «Эффект старого экрана»; подключить зарядку (в режиме экономии видеокарта замедляется) |
| Нет звука | Esc → Настройки → проверить «Общая громкость»; проверить устройство вывода звука Windows |
| «Steam: не запущен», хотя Steam открыт | Проверьте, что `steam_appid.txt` и `steam_api64.dll` лежат в одной папке с игрой; перезапустите игру после Steam |
| Игра не видит прежние сохранения после обновления | Сохранения лежат в `%APPDATA%\GodShpionov\saves` и переносятся между версиями сами; если версия старая, игра честно скажет, что формат другой |

**Запуск через DirectX** (если OpenGL не работает): правой кнопкой по `GodShpionov.exe` →
**Создать ярлык**. Правой кнопкой по ярлыку → **Свойства** → в поле «Объект» после пути к игре
допишите через пробел:

```
--rendering-driver opengl3_angle
```

→ **OK**. Запускайте игру этим ярлыком.

Если игра всё равно не работает — пришлите `%APPDATA%\GodShpionov\logs\godot.log`, модель
видеокарты и версию Windows.

## Обновление

Скачайте новую сборку тем же способом и распакуйте поверх старой папки (с заменой файлов) или в
новую папку. Сохранения и настройки останутся — они лежат отдельно, в `%APPDATA%\GodShpionov`.

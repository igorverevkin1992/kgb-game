# План разработки «Год шпионов»

## Контекст
Есть Concept Bible и базовый GDD на 45 страниц. Это диегетический UI-симулятор резидента ПГУ на 7–10 часов: 4 акта, 6 модулей рабочего стола, 4 шкалы риска, пирамида вербовки из 6 фигур и 4 концовки. Нужен пошаговый план, по которому игру соберём вдвоём со мной. Первая цель — **играбельный вертикальный срез (Акт I, 40–60 минут)** по разделу концепта «Состав MVP за 8 недель». Дальше — Акты II–IV и релиз в Steam и VK Play.

**Что уже решено:**
- **Стек:** Godot 4.7 + GDScript, рендерер Compatibility (рекомендация концепта и исследования жанра; переезд с Electron + React + TS после шага 4).
- **Кто что делает:** ты «немного кодил». Код пишу я и объясняю ключевые места. Ты решаешь, что делаем, пишешь и правишь тексты и данные (JSON), играешь в билды и даёшь обратную связь.
- **Платформа:** только Windows (x64). macOS и Linux не делаем, хотя в концепте они указаны.
- **Где код:** ты создаёшь пустой репозиторий на GitHub и даёшь мне `owner/repo`. Я подключаю его и пушу каждый шаг: контейнер временный.

## Технические решения
| Слой | Выбор | Зачем |
|---|---|---|
| Движок | Godot 4.7, GDScript, рендерер Compatibility (OpenGL 3.3 / D3D11) | Рекомендация концепта и исследования; работает на встроенной графике, MIT без роялти |
| Логика | Чистый GDScript в `engine/`: функции над словарями, без узлов | Движок кампании и валидатор тестируются без экрана |
| Данные | JSON в `content/` + своя проверка схем (`engine/schema.gd`) | Пользователь правит JSON, ошибки — по-русски |
| Диалоги | Свой формат бесед в JSON (`content/dialogs/`): реплики по тонам и козыри из досье; валидатор проверяет, что беседу можно выиграть | Ink для Godot требует C#, а с C# нет веб-сборки; систему «тон + козырь» из концепта удобнее описывать данными |
| Тесты | `tools/test.sh` (unit, headless) + `tools/ui-test.sh` (сценарии интерфейса под Xvfb, скриншоты) | Приёмка каждого шага автоматически |
| Валидатор контента | `tools/validate.sh`: схемы, «Правило трёх улик», тупики, проверочный маршрут | Закрывает риск №1 из концепта |
| Сборки | Экспорт Godot: Windows `.exe` (встроенный pck) и Web (без потоков) — в CI | `.exe` — артефакт CI; веб-версия — на GitHub Pages |
| Steam | GodotSteam (шаг 10) | Overlay, достижения, облачные сохранения |
| Локализация | Сначала только русская версия (`i18n/ru.json`); английская — после, с редактурой носителем | Решение пользователя |

**Структура репозитория:**
```
content/      — JSON: кампания, баланс, карта, цели, улики, депеши, операции, полиграф
engine/       — логика: схемы, загрузка и правила контента, кампания, сохранения, карта
ui/           — интерфейс: кабинет, модули, оверлеи, стиль, строки
i18n/         — строки интерфейса (ru.json)
assets/       — шрифты PT, SVG-плейсхолдеры
tests/        — unit-тесты (test_*.gd) и сценарии интерфейса (tests/ui/)
tools/        — get-godot.sh, validate.sh, test.sh, ui-test.sh, export.sh
```

## Пошаговый план

Каждый шаг рассчитан на одну-две рабочие сессии со мной. Шаг заканчивается коммитом, пушем, зелёными тестами и тем, что ты можешь в нём потрогать.

### Этап 0. Подготовка (1 сессия)
0. **Репозиторий и каркас.** Ты создаёшь репозиторий. Я подключаю его и ставлю Vite + React + TS, ESLint, Vitest, Playwright, CI в GitHub Actions. Переношу концепт в `docs/` (GDD в Markdown, чтобы я мог на него ссылаться).
   *Приёмка:* `npm run dev` открывает пустой «кабинет», CI зелёный.

### Этап 1. Вертикальный срез: Акт I (≈ 8 недель по концепту)
1. **Схемы данных и валидатор** (нед. 1). Zod-схемы для целей, улик, операций, депеш и полиграфа по образцам из Блока 6. `tools/validate.ts` с проверкой «Правила трёх улик». Заглушечный контент Акта I.
   *Приёмка:* `npm run validate` ловит специально сломанную улику.
2. **Движок кампании** (нед. 1–2). Стейт-машина операционной недели (4 фазы), 4 шкалы риска (SOG Heat, Mole Hunt, Treasury, Давление Центра), флаги последствий, сохранение и загрузка (localStorage, позже файл в Electron).
   *Приёмка:* unit-тесты прогоняют 3 недели с разными решениями, сейв и загрузка дают то же состояние.
3. **Кабинет и переключение модулей** (нед. 2). Диегетический стол: клик по объекту открывает модуль, без меню. Базовая палитра «Контейнера» (оливковый, охра, ГОСТ-бланки), шрифт под «Ятрань».
   *Приёмка:* переключение 4 модулей быстрее 0,2 с (замер в Playwright).
4. **Карта SDR** (нед. 3). SVG-карта: 5 локаций, 25-мильный радиус, конструктор маршрута из 3 точек, карточки примет, механика «дважды — работа противника», отмена операции, последствия в SOG Heat.
   *Ты:* пишешь тексты примет и локаций (я дам шаблон JSON).
5. **Доска MICE и картотека** (нед. 3–4). Пробковая доска, досье с 4 скрытыми шкалами, перетаскивание улик в ячейки, «красные линии», подсветка выводов, подтверждённых тремя уликами.
   *Практики (`docs/best-practices.md`):* карточка из трёх полей (мотивация, доступ, канал) с проверкой пакетом из трёх и мягкой подсказкой «1–2 элемента неверны»; подсвеченные фрагменты-улики в документах; счётчик «Интуиция»; подсказки намёк → документ → ответ; продуктивные ложные следы.
6. **Шифроузел «Фиалка»** (нед. 4). Входящие депеши Центра и сборка ответной шифрограммы из смысловых блоков. Дилемма «доложить правду или причесать» с влиянием на Давление и Доверие Центра.
   *Приёмка этапа:* игрок проходит одну полную неделю: директива → SDR с хвостом → 2 открытые оси MICE.
   *Практики:* короткий ритуал (ключ роторов → запуск → авторасшифровка за 1–2 с), контрольные группы против дезинформации, выбор, что отправить сегодня; настройка мгновенного вывода текста.
7. **Вербовочный диалог** (нед. 5). Беседы в JSON (Ink требует C#), стенограмма и магнитофон «Тембр-2М», индикаторы Раппорт и Тревога, выбор флага (чужой или свой), козыри из досье, «прерви и вернись в другой день».
   *Ты:* правишь первую версию бесед Варгас и Кэллоуэя (`content/dialogs/`, формат — в `docs/content-guide.md`).
   *Практики:* без таймеров, «Прервать контакт» в любой момент, катушка с расшифровкой и таймкодами (пробел/стрелки), оговорки переносятся на доску MICE, пропуск виденных реплик.
8. **Финансовый журнал (база)** (нед. 6). Спецфонд, транши, порог CTR $10 000 и инструменты выплаты (наличные, эскроу). Полная ветка вербовки Элен Варгас.
   *Приёмка:* Акт I замкнут от вводной до успешной или провальной вербовки.
   *Практики:* три открытые шкалы по агенту (лояльность, банковский след, образ жизни), экстренный транш из Центра вместо «спирали бедности».
9. **Арт и звук** (нед. 7). ЭЛТ-шейдер (виньетка, зерно), стилизованные бланки, контраст «американских» артефактов, диегетические SFX (роторы, бумага, катушка), эмбиент. Перевод на английский.
   *Ты:* выбираешь или заказываешь ассеты. Я подскажу бесплатные источники SFX и шрифтов и сгенерирую плейсхолдеры.
   *Практики:* финальный арт — авторский, без генеративного ИИ; ЭЛТ-эффекты отключаются в настройках; предметный звук с нормализацией громкости, без озвучки.
10. **Steam и плейтест** (нед. 8). Windows-сборка Godot (уже собирается в CI), GodotSteam, проверка Overlay (Shift+Tab), тест на встроенной графике, телеметрия точек застревания (локальный лог). Закрытый плейтест на 15–25 человек.
    *Приёмка:* ≥80% тестеров доходят до конца Акта I, софтлоков нет.
    *Практики:* плейтест с интервью и картой «Пути мысли» (где застряли, где перескочили).

### Этап 2. Полная кампания (≈ 4–6 месяцев)
11. **Акт II «Периферия»** (вторая фаза операции): второй эшелон (Хэйлс, Дженкинс, Мендоса, Кэллоуэй), мёртвые закладки в парках Вирджинии, делегирование рутины двум оперативникам (риск №4), раскрытие «Монополии».
    *Практики:* новые приёмы ФБР на SDR по одному в «тихие» недели (эстафета машин, смена одежды, самолёт), никогда в неделю с сюжетным диалогом.
12. **Акт III «Кронос»:** трёхфазная сцена «Ужин в Джорджтауне», проверка на подставу (dangle check), событие с перебежчиком, получение «Списка».
13. **Акт IV «Список»:** пульт «Окно арестов» (18 карточек, 8-недельный график, квоты Центра, оперативная игра), режим MLCA 1986 в финансах, индикатор образа жизни «крота».
    *Практики:* «Давление Центра» ↔ «Воронка ANLACE» (198 → 64 → 29), по делу три линии: арест / упаковка под утечку / отложить.
14. **Полиграф:** предтестовая подготовка и пошаговый допрос Comparison Question Test с тремя кривыми. Формула прозрачная (50% подготовка / 50% тактика), есть репетиция.
15. **4 концовки и эпилог** (хроника 1985–1994). Балансный прогон всех веток через автосимуляцию движка.
    *Практики:* эпилог-хроника до 1994 года о судьбе каждого источника.
16. **Контроль объёма:** «бриллиантовое ветвление» и счётчик слов в валидаторе (лимит 45–60 тыс. слов), редактура EN носителем языка.

### Этап 3. Релиз
17. Страница в Steam, трейлер и скриншоты (Playwright снимает кадры с нужными сценами), демо на Steam Next Fest.
    *Практики:* страница минимум за 12 месяцев до релиза, редкие теги (Detective, Investigation, Conspiracy, Cold War, Political Sim); цена $14,99–17,99, скидки в первый год не глубже 20–25%; редактура EN носителем.
18. VK Play: эмуляция Steam или GamePush, сборка под Windows.
19. Бета, исправления, релиз, патчи по телеметрии.

## Как мы работаем
- **Ритм:** ты открываешь сессию и пишешь «делаем шаг N». Я читаю `docs/` и код, реализую шаг, прогоняю тесты и Playwright-скриншоты, пушу. Ты играешь и пишешь замечания.
- **Твоя зона:** тексты, беседы (JSON), баланс чисел в JSON, решения по дизайну. Валидатор сразу скажет, если правка что-то сломала.
- **Моя зона:** код, схемы, тесты, CI, сборки, объяснения по ходу.
- **Память проекта:** `CLAUDE.md` в корне репозитория (договорённости, структура, команды). Каждая новая сессия стартует с контекстом.

## Проверка (сквозная)
- `tools/test.sh`: unit-тесты движка и валидатора.
- `tools/validate.sh`: схемы, «Правило трёх улик», тупики, проверочный маршрут.
- `tools/ui-test.sh`: сценарии интерфейса под виртуальным экраном, скриншоты модулей.
- CI на каждый push, веб-билд доступен тебе для ручной игры.
- На шаге 10: Windows-сборка из CI. Ты запускаешь `.exe` у себя и проверяешь Steam Overlay: в облачном Linux-контейнере это не проверить.
